The stat tile used for "My Journey" on the member dashboard and "Key Metrics" on the org dashboard: a coloured icon circle, a large number, and a label. Four icon colour modifiers are available, success / warning / info / primary, reusing the same soft colour tokens as Alerts and Badges.

On the org dashboard, the same tile sits inside .org-metrics-grid, a fixed 5-column grid used to guarantee exactly 5 tiles per row regardless of width (deliberately not the shared flexbox-based .grid-3 above, which instead wraps tiles to fewer per row as space runs out). Because the column count never changes, tiles get proportionally narrower as the viewport shrinks: below 1650px wide the label moves under the value and the icon hides to keep both readable; below 1100px, .org-metrics-grid itself collapses to a single column, so the icon and inline label return since there is room again. Resize your browser to see all three states.

Sidebar navigation actions
New

Two controls anchored at the top of both dashboard sidebars, sitting side by side on the dark sidebar background.

Click the hamburger circle above to preview the stacked spacing used when the real sidebar is collapsed (.dashboard-shell.is-collapsed .sidebar-top-actions).

Back arrow. Calls history.back() directly. This works today because every page here is a full server-rendered reload. If the dashboards move to a client-side router (for example React Router), this needs to be swapped for the router's own back/navigate call, or it will fall outside the SPA's history stack and can leave the app in an inconsistent state.
Hamburger circle. Calls sidebarCollapseToggle(), which toggles .is-collapsed on the dashboard shell. This shrinks the sidebar from --sidebar-width (280px) down to --sidebar-collapsed (84px), hiding labels and centring icons. It only collapses the desktop rail, it does not open the mobile drawer, that is a separate hamburger in the topbar wired to mobileSidebarToggle().
